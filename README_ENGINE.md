# LBR 数据与研究引擎

此目录使用 Python 3.10+ 标准库，无需 pip。原 `BIG A GO_super` 未被修改。

```powershell
python scripts/update_data.py
python scripts/update_data.py --offline
python -m unittest discover -s tests -v
python scripts/learning.py --ledger "私有完整交易导出.json"
python scripts/backtest.py
```

行情正常时更新 `data/latest.json`、`quotes.json`、`events.json`、`history-cache.json`；失败时保留旧数据、原始报价时间并显示 `stale`。正常刷新失败退出 2，离线安全回退退出 0。脚本可供原有 16 个 Actions 定时点调用；定时任务不是分钟级实时行情承诺。

`latest.json` 是备选池合同；`quotes.json.quotes` 以 `600000.SH` 等完整证券代码为键，保留已离开备选池的全部可取得行情。缺失标的保留旧报价并标 stale。原始价格来自东方财富，必要时使用新浪证券清单与腾讯真实报价回退。未取得的股票不生成演示行情或买卖推荐。新浪显式创业板、科创板清单不完整时，其余标的分类为 UNKNOWN，不能进入主板池；代码前缀只做额外否决校验。

用户当前要求覆盖 Word 中的五日初值：备选批次每 7 个实际交易日轮换，行情每日更新；持仓从首次实际买入日算第 1 日，第 7 日提醒人工处理。追加买入不重置首次买入日。买入份额 30% / 30% / 40% 只用于计划资金，A / B 是独立的 11% / 13% 回撤价格档。站点不连接券商、不自动成交；触价和告警都不修改实际余量。

交易日来自指数真实日线、具有成交额的实际报价日期，以及可选的 `config/trading-calendar.json`（必须带 `verified: true`、`source` 和明确 `sessions`）。不使用普通 weekday 冒充官方交易日历。未覆盖的未来第 7 日为 null，须显示“待交易日历确认”。观测日历只能证实已有交易日，不代表已核验未来休市安排。

`scripts/strategy.py` 提供 Decimal 价格公式、门禁、真实日历、版本重锚、批次轮换、人工多笔合并和 T+1 管理。触发价按最小报价向下取整；目标与止损使用文档公式。T0 全天最低价可能发生在首次触板前，因此不能单独证明事件发生后的回撤触价。新的峰值取消旧触达状态、递增事件版本。买后目标必须使用成交当时已知的峰值与确认低点；缺确认低点仍可记录真实成交，但最终目标留空待补。历史 support 仅是 T0 前 20 日最低价代理，不是已核验结构支撑。

公共接口缺少公告风险、正式证券状态、盘口、账户同步和连续 20 日相同时槽的 5 分钟成交额基线。因此正常公开数据只给 WATCH 和参考价，不能伪装成 BUY_READY。代码支持输入完整且新鲜的验证数据后执行确认门禁，但本站未接入该类付费/券商数据源。吸筹得分不是成功概率。历史复权日线只供趋势研究，实际上下限和成交使用非复权报价；公司行动与结构验证缺失会阻止可执行信号。

全量事件保存在 `data/events.json`，包括否决和未成交事件；每次评估追加到 `data/audit.jsonl`，参数版本保存在 `data/parameter-audit.json`。未成交不算亏损，日内最高价不冒充已成交卖出价。

`learning.py` 兼容网页完整的 `lbr-portfolio` v1 导出：分币价格与费用、事件 snapshots、卖出 allocations.buyFillId 和成本费用分配。它按原买入事件归属统计实际平仓结果，保留未成交与未平仓事件。默认报告为私有 `learning/reports/latest.json`，应被 Git 忽略；禁止把个人成交报告放到公开 `data/`。少于 30 个事件只检查数据，不推断稳定胜率；30–99 仅描述统计；达到 100 也仅进入待时间前推样本外研究。任何阶段不自动更改门槛，不承诺提升胜率。

私有报告同时生成 `ruleResearch.candidateRules`：可执行的 `field / equals / value` 影子筛选器与训练/验证统计。采用按日期 70/30 切分，剔除跨组同股事件，记录训练日期范围和参数哈希；回撤/模式等分组使用买入时的事件快照，避免未来信息。少于 100 个唯一事件或 100 个真实平仓事件、分组样本不足、缺少时间外验证、不同市场阶段未核验时，规则明确 blocked。没有自动调整推荐门槛，也没有把此描述为已训练好的 ML 模型。

`backtest.py` 当前明确输出 A / B / C 三方法的缺数据准备报告，**不是已完成绩效回测**。缺少可核验分钟历史、决策时点证券元数据和可执行成交/费用模型时，不生成胜率、收益或回测曲线。
