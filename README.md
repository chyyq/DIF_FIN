# LBR 涨停深回撤波段研究台

这是基于 `BIG A GO_super` 静态框架重新实现的独立项目：浏览器页面 + 本地交易记录 + Python 数据生成器 + GitHub Actions + GitHub Pages。页面的两项核心工作是维护备选池，以及跟踪人工确认买入后的持仓。LBR 的买卖逻辑与旧早盘涨停、尾盘 T+1 模型隔离。

已实现七日备选池、人工成交与同股合并、独立持仓监控、冻结分笔目标、事件样本和演示隔离。页面仍以实际数据时效和证据完整性决定状态，部署文件的存在不代表线上服务已开通。

## 策略与使用口径

- 备选池以批次保存，默认以 **7 个交易日**为一轮更换；批次内持续更新行情、状态、事件高点、价格阶梯和失效信息，不把每次行情更新当成重新选池。
- 人工确认买入后进入独立的 **7 个交易日**跟踪；同一股票合并为一张持仓卡，多笔买入保留成交明细并更新数量与加权成本。第 7 个交易日警示后由用户处理，系统不自动卖出。
- “7 天”按你确认的交易日实现，优先于 Word 原有 5 日期限；这是可配置的初始口径，日历和停牌数据必须核验。重复加仓不会让旧持仓期限无限顺延。
- 快捷买入比例为计划仓位的 **30% / 30% / 40%**，用于填写人工实际成交记录。参考触发价、计划仓位比例都不等同于券商实际成交。
- 价格应显示事件涨停日期、涨停价/高点基数、低吸触发价与买入上限、两档止盈和止损，以及相对基数或成本的比例。缺关键证据时保持观察或失效，不以空缺字段生成可买信号。
- 止盈、止损和期限到达只提供提示；买卖执行、实际价格、数量和费用由用户确认。A 股当日买入数量的可卖限制应按实际交易日处理。
- 演示模式的数据与交易存储应与真实模式隔离；演示股票、收益和统计不得混入真实学习样本。

## 本地运行与验证

Windows 优先使用一键启动脚本。它会查找已安装的 Node.js 或本机 Codex 附带的 Node.js，成功监听本地端口后再打开浏览器；不需要安装 npm 依赖或构建。

```powershell
cd "C:\Users\28931\Documents\ChatGPT\Doby is free\LBR-wave"
.\Start-LBR.ps1
```

默认地址 `http://127.0.0.1:8000`；关闭服务窗口或按 `Ctrl+C` 停止。可用 `-Port 8001` 更换端口，`-NoBrowser` 仅启动服务。已经安装 Node.js 20+ 时，也可用 `npm run dev`。本地服务器仅对本机开放，并限制对个人学习资料、Git 文件和部署脚本的访问。不要直接双击 HTML：浏览器本地文件限制会影响 JSON 与模块加载。

数据生成和离线学习另需 Python 3.11+，脚本只使用标准库；GitHub Actions 会自动配置 Python。本机 `python` 不在 PATH 时，可用 Codex 附带的 Python 执行同一脚本。

```powershell
python scripts/update_data.py
npm run test:js
npm run test:py
```

`npm test` 顺序执行上述两组测试。首次没有可核验行情时应显示数据不足；不能把演示行情当成实时行情。

## 刷新机制

沿用旧项目工作流实际配置的 16 个 UTC 定时任务，而非旧 README 已过时的 4 个时刻：

| UTC（周一至周五） | 中国时间 |
| --- | --- |
| 01:26 / 01:29 / 01:32 / 01:35 / 01:38 / 01:40 | 09:26 / 09:29 / 09:32 / 09:35 / 09:38 / 09:40 |
| 05:30 / 05:45 | 13:30 / 13:45 |
| 06:00 / 06:10 / 06:20 / 06:30 / 06:35 / 06:50 | 14:00 / 14:10 / 14:20 / 14:30 / 14:35 / 14:50 |
| 12:00 | 20:00 |
| 16:00 | **次日** 00:00 |

最后一项的 UTC 周一至周五对应中国周二至周六零点。零点运行只维护 LBR 状态，不能沿用旧策略的“每天午夜清空推荐”。周末与交易所休市不是同一概念；数据生成器必须结合交易日历与行情日期校验，不能仅依赖 cron 的周一至周五。

GitHub Actions 可能延迟、跳过或因公共接口限流失败，它是定时快照任务。网页刷新按钮只会读取服务器最新文件；生成时间没有变化时，应明确提示。页面打开时可进一步轮询分钟行情；页面关闭、设备离线或浏览器休眠时不能保证追踪高低点或及时提醒。完整的盘中高低点与实时缩量确认需要足够完整的分时数据。

## GitHub 与 Pages 配置

新项目尚未配置新的 GitHub 仓库或远端。原 `BIG A GO_super/.git` 是空目录，不能据此恢复可信 Git 历史或远端；旧 README 的在线地址不应被自动用作新项目发布目标。

1. 在 GitHub 创建一个新的空仓库，默认分支使用 `main`，并将本目录作为仓库根目录。公开发布时仅上传可公开代码和市场数据；人工交易与证据资料留在本地。
2. `Settings → Actions → General → Workflow permissions` 允许 `Read and write permissions`，以便数据工作流提交 `data/`。
3. `Settings → Pages → Build and deployment → Source` 选择 **GitHub Actions**。
4. 推送 `main` 后运行 `Deploy LBR Pages`；随后可在 Actions 手动执行 `Update LBR market data` 获取首份行情。
5. 在 Actions 与 Pages 查看实际成功状态和发布地址；上线后检查 JSON 的生成时间和来源状态。

这里修复了旧“从分支发布”的一个限制：使用 `GITHUB_TOKEN` 推送的数据提交不会触发新的 Pages 构建。因此 `deploy-pages.yml` 通过成功完成的数据工作流 `workflow_run` 显式部署，并检出最新 `main`；人工推送与手动触发也可部署。[GitHub 官方说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

部署产物仅包含根目录 HTML/CSS/JS/SVG（包括 `favicon.svg`）、`src/`、`assets/` 和 `data/`，不会把本地学习原始资料发布出去。不要把个人交易、密钥或非公开证据放进 `data/`，该目录会被公开发布。

可选 PowerShell 辅助命令（本项目交付时未执行推送）：

```powershell
.\DEPLOY.ps1 -RepositoryUrl "https://github.com/你的账号/你的新仓库.git"
# 检查本地代码与远端地址后，再明确推送：
.\DEPLOY.ps1 -RepositoryUrl "https://github.com/你的账号/你的新仓库.git" -Push
```

脚本只初始化本目录的 Git 仓库，默认不进行网络推送，不覆盖已有不同 `origin`，不强制覆盖远端。需要使用已配置的 Git 身份和 GitHub 登录凭据；不要把访问令牌写进代码或 URL。

## 数据和学习边界

旧框架采用东方财富公开行情/日线接口、公开资讯以及可选 Yahoo 历史证据，无需提交个人行情密钥；这些非专属接口可能发生字段变化、封禁、延迟或数据缺失。可用接口不等于已获得交易所完整证券主档、官方涨跌停价、停复牌、除权和公告核验。关键静态数据、交易日历、分钟量能或公司行动无法可靠核验时，应降低状态而非补造事实。

人工买入、加仓与卖出记录存放在当前浏览器 `localStorage`，需要主动导出 JSON 备份或在设备间导入。浏览器清理、隐私模式或换设备会影响本地记录；GitHub Pages 不提供私有数据库或账户同步。导出资料可供本地学习脚本读取，默认忽略 `reference/` 和学习产生的个人文件。

本地学习报告应保存在被忽略的个人目录，例如：

```powershell
python scripts/learning.py --ledger "reference/你的导出账本.json" --output "learning/reports/latest.json"
```

不要将带实际交易的报告输出到公开 `data/`。部署流程额外排除了旧默认名 `data/learning.json` 及账本导出文件，作为防止误发布的补充措施。

所有实际交易均可形成样本，但只有用户确认的成交价格/数量/结果才能作为已实现收益与胜负标签。未卖出、未标记、缺失成交事实的记录保持待补；涨跌高低点仅作行情观察。样本分布、胜率、最大有利/不利波动和候选规则用于研究，不能承诺提高未来胜率。样本不足、多日期覆盖不足、或没有通过独立检验时，不应自动修改正式策略。此静态版本不具备后台自动云端学习，不连接券商，不自动发单。

## 本机快捷操作

运行 Update-LBR.ps1 可自动定位本机 Codex Python 并刷新公开数据；无需先把 Python 加入 PATH。网页刷新按钮读取生成结果，页面打开时另外尝试每分钟更新已持仓和备选股票报价。

离线学习还会生成受独立事件数、训练与验证日期、同股隔离、市场阶段和尾部收益约束的规则候选。它们只用于影子研究，未通过检验不自动作用于正式推荐。完整 A/B/C 收益回测目前缺少盘中历史证据，准备状态和缺失清单见 data/backtest-readiness.json。
