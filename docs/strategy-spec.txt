LBR  ·  量化策略规范 v1.0
涨停强势股深度回撤低吸与 2—5 日修复波段策略
自然语言规则  ·  数据字段  ·  状态机  ·  每日报表  ·  回测验收

使用定位  交付给 Codex 的可实现策略需求说明；独立于现有早盘打板与尾盘 T+1 模块。每日输出不超过10只候选、2档低吸价与2档止盈价，支持最长5个交易日的监控，不保证一定成交。

策略范围：默认沪深主板、正常涨跌幅限制、非ST；明确排除创业板。科创板和北交所默认关闭，可单独启用独立参数模型，不混入主板样本。
参数状态：所有百分比、分数与持有期限是可回测的初始假设，不是收益保证或统计最优值。
版本日期：2026-10-23。交易规则以交易所当时生效文本及券商可用接口为准。

1. 策略定位、范围与模块隔离
1.1 策略假设：处于中期上升趋势的沪深主板股票，触及涨停后可能出现资金集中兑现、短期流动性冲击或深度换手；在其关键趋势结构未失效、抛压减弱并重新获得承接后，未来2—5个交易日可能出现一定幅度修复。该假设必须被完整事件回测验证。
1.2 交易动作：每天筛选不超过10只，给出预先计算的价格阶梯，等待回撤落入区间并通过缩量/承接触发器后入场；未触发不交易；买入后根据事先锁定的两档止盈价、结构止损和时间止损管理。
1.3 严格隔离：LBR不得修改既有早盘抓涨停板策略与尾盘T+1策略。三者应有独立strategy_id、资金预算、候选池、交易日志、收益与回撤统计，避免同一标的策略重复占用风险。
1.4 交易标的：默认主板A股（交易所instrument_segment识别为SSE_MAIN/SZSE_MAIN），排除创业板、科创板、北交所、ST/*ST、退市整理、上市初期无涨跌幅限制、停牌、无有效交易数据、流动性过低或异常风险证券。科创板仅作为未来可配置独立实验组，不应套主板10%限制。
1.5 不以“次日必须高开”为目标，不承诺涨停后必然回补；本策略允许T0当天买入，但当天买入的股票通常最早T+1才可卖出。

3.2 事件与回撤的精确定义
event_id = symbol + first_limit_touch_trade_date + event_sequence
T0 = first intraday touch of actual exchange upper_limit_price
H_asof(t) = max(actual traded high observed since T0 through t)
drawdown(t) = (H_asof(t) - last_price(t)) / H_asof(t)
D0...D4 = five trading sessions including T0; calendar days do not count
若T0之后再次创出事件新高，在尚未持仓时旧参考价格需要取消并重新生成新版本（version++）；不允许事后用未来最高价回填历史信号。买入后冻结该笔交易的入场时事件高点H_entry与确认低点L_entry，以防卖点无限随行情漂移。若T1—T4期间再次涨停，可定义新事件，但同一股票仅保留一个有效的、最新且结构合理的事件；旧未成交订单须先撤销确认。

两档规则：默认“择一入场（OCO）”，不是同时向交易所长期挂两张越来越低的普通买单。A档先形成成交后，B档自动禁用；若A档未成交，价格进一步下跌至B档，则重新验证并允许B档触发。无法保证撤单同步时，只允许一档处于已提交状态。
可选分批模式（默认关闭）：A档已成交后，B档仅能在新的独立止跌信号、原低点未再被有效击穿、累计风险预算仍有余额时获准；严禁只因“跌到B价”便加仓摊薄成本。
5.2 价格锚与支撑过滤
纯回撤比例决定初步价格，历史支撑决定该价格是否合理。计算并记录：近20日平台突破位、MA10/MA20、最近有效波段低点、过去20日成交密集带、ATR14和最近事件高低点。若预测买价下方缺少有效结构支撑，或关键支撑已被有效跌破，该档降级/作废，而非强行把买价移动到支撑位。
6. “缩量抄底”的可计算定义与确认机制
6.1 两种认可的成交结构
1.  PANIC_ABSORPTION：先出现显著放量下杀，随后5分钟成交量与负向价格冲击下降；价格连续10—20分钟不再创新低，形成初步承接。
2.  ORDERLY_PULLBACK：回调过程较平缓，成交量相对于该股历史同一时段基准缩小，同时跌幅进入目标区，低点结构未破；没有“放量恐慌”仍可作为缩量回踩候选。
两种结构分开打标签，不能强迫所有样本先放量恐慌再缩量。T0真正天地板往往是异常风险事件，不可简单以“成交量减少”推断安全。

7. 预计买价、卖价与止损价的计算方法
7.1 买点两档与实际执行上限
每个买档包括：价格触发价 P_touch（最低必须曾触达），最大买入限价 P_cap（承接确认后允许的最高成交价），确认标志 Confirm。为了把用户展示压缩为具体数字，日报显示“跌到多少开始观察、确认后最多多少钱买”。若实际反弹时超出P_cap，本笔不追。
7.2 两档止盈价（预估与成交后冻结）
For each candidate buy zone j:
  H = event_peak_asof_report
  L_ref_j = trigger_price_j  # pre-trade proxy, not future actual bottom
  raw_TP1 = L_ref_j + 0.382 * (H - L_ref_j)
  raw_TP2 = L_ref_j + 0.618 * (H - L_ref_j)
  TP1 = round_tick_down(raw_TP1)
  TP2 = round_tick_down(raw_TP2)
 
After actual fill:
  E = actual_weighted_average_fill
  L_entry = confirmed_pivot_low_known_at_fill
  freeze_trade_targets_using(H_entry, L_entry, E)
  flag_exit_review_if_target1 <= E or payoff_deteriorates
  stop_ref = min(confirmed_structural_support, L_entry)              - max(0.5*ATR14, 0.01*L_entry)
止盈分档比例初始50%/50%；若第一目标接近历史密集套牢区或平台阻力，允许将其下调到该阻力前一档报价，但若因此使收益风险比不足则不发买入信号。回撤0.382/0.618仅是便于统一比较的参考网格，后续应与ATR倍数及结构阻力法做严格样本外对照，不视为自然规律。

RR = (0.5*(TP1-entry_cap)+0.5*(TP2-entry_cap)) /      max(entry_cap-stop_ref, tick)
position_value = min(
    account_equity * per_trade_risk_budget / max(planned_loss_pct,eps),
    account_equity * stress_risk_budget / max(stress_loss_pct,eps),
    portfolio_remaining_risk_capacity,
    symbol_liquidity_cap
)

9.3 日报调度
1.  盘前：检查全部在有效期的旧事件，先作废失效订单，再重新核验价格带、交易状态、公告与风险预算；发布当日可用方案。

12.1 决策伪代码
def daily_lbr(snapshot, portfolio, broker):
    events = find_limitup_events(snapshot, allowed_segments=['SSE_MAIN','SZSE_MAIN'])
    pool = merge_active_events_with_new(events, max_age=4)
    eligible = []
    for e in pool:
        if hard_veto(e, snapshot, portfolio):
            cancel_or_disable_pending(e)
            continue
        if not all_gates(e, snapshot):
            set_status(e, 'WATCH')
            continue
        issue_precomputed_price_plan(e)  # A/B trigger + cap + TP1/2
        eligible.append(e)
 
    visible = rank_and_diversify(eligible, limit=10, max_per_sector=2)
    for e in eligible:
        if not realtime_confirmation_available(e):
            set_action(e, 'WATCH_NO_BROKER_ORDER')
        elif is_broker_state_unknown(broker):
            set_action(e, 'PAUSE_NEW_ORDERS')
        elif triggered_and_absorbed_and_reclaimed(e) and payoff_ok(e):
            set_action(e, 'BUY_READY')  # authorize broker action separately
        else:
            set_action(e, 'WAIT_CONFIRM')
    return visible

13.2 必须比较的三组买入方法
1.  A基准：只按“价格触达8%—16%”挂普通被动限价单（研究基准，不默认实盘启用）。
2.  B：价格触达 + 相同时段归一化缩量 + 不创新低，满足时发条件买单。
3.  C：B + 局部VWAP重新收复或突破短反弹高点，但成交价格不得超过EntryCap。
分别比较T0与T1—T4、回撤档位、板块风格以及持有E+1/E+2/E+3/E+5的历史净收益中位数、正收益比例、尾部亏损、最大回撤、成交比例、资金使用效率。不得只优化胜率、单次最大盈利或事后最低点成交。
13.3 回测分割及防止过拟合
样本<30个独立事件：仅检查代码、成交语义、数据完整性；不推断稳定胜率。
30—99事件：允许描述统计、敏感性分析，不自动改变核心门槛。
≥100事件且覆盖不同市场阶段：使用按时间前推的训练/验证/样本外测试；同一股票相邻事件按组隔离，避免泄漏。
版本保留参数快照：每次门槛更改须记录生效时间、训练范围、验证收益、最大回撤、淘汰条件；上线后采用影子交易/小规模真实成交校正滑点。
